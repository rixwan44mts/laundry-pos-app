Privacy policy

Laundry POS, by Precision Technologies. Effective 1 November 2026.

Who this applies to

Laundry POS is software that a laundry or dry-cleaning shop installs on its own computer. This policy explains what the software does with information, including information from Google when the shop owner connects Google Drive.

Shop data stays on the shop's computer

Orders, customers' names and phone numbers, payments, expenses and staff records are stored in a database on the shop's own computer. They are not sent to Precision Technologies or to anyone else. The shop owner controls this data.

Google Drive backups

If the shop owner chooses Connect Google Drive and signs in with Google, Laundry POS asks for:

  • Google Drive — files created by this app only (drive.file). Laundry POS uses it to create a folder named LaundryPOS Backups, upload the shop's encrypted backup files into it, list and download those same files to restore a backup, and delete old backup files it created (it keeps the last 30, plus one per month for 12 months). It cannot see, open or change any other file in the owner's Drive.
  • The owner's email address (email, openid), shown in Laundry POS so the owner can see which Google account is connected.

Backups are encrypted on the shop's computer before they are uploaded. Without the shop owner's backup password or recovery key, the backup files cannot be read — not by Precision Technologies, not by Google, and not by anyone else with access to the Drive.

The permission Google gives (a sign-in token) is stored only on the shop's computer, in a folder that ordinary Windows users cannot open. It is never sent to Precision Technologies.

Google API Services User Data Policy

Laundry POS's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

  • Google user data is used only to provide the backup feature described above.
  • It is not sold, not used for advertising, and not transferred to others.
  • No person reads it; it is handled only by the software on the shop's computer.

Stopping and deleting

  • The owner can click Disconnect in Laundry POS (Admin Dashboard → Backups & Safety). This cancels the Google permission and removes the token from the computer.
  • The owner can also remove Laundry POS at myaccount.google.com/permissions.
  • Backup files already in Drive stay in the owner's Drive until the owner deletes them.
